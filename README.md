# Basic Programming – Semester 1 (Java)

This repository contains exercises, case studies, and practical assignments from the **Basic Programming course** using **Java** during my first semester in Informatics Engineering.

The purpose of this repository is to document my learning progress in fundamental programming concepts such as control structures, arrays, methods, and basic object-oriented programming.

---

## Concepts Covered

During this course, several fundamental programming concepts were learned and practiced:

* Variables and Data Types
* Input and Output
* Conditional Statements
* Loops
* Arrays
* Methods
* Basic Object-Oriented Programming
* Encapsulation

## Folder Description

CASEBASED_PEMDAS
Contains case-based programming exercises that apply basic programming logic to solve specific problems.

PRAKTIKUM_PEMDAS
Contains weekly programming assignments from practical sessions.

Tugas6 introduces a simple program simulating a **library system** using basic object-oriented programming.

Tugas7 focuses on **encapsulation and simple object-oriented design**.

TEORI_PEMDAS
Contains example programs used to understand core programming concepts such as loops, arrays, conditions, and mathematical operations.

TugasArray
Contains exercises related to array manipulation and problem solving using arrays.

## How to Run

1. Compile the Java file

``` text
javac FileName.java
```

1. Run the program

``` text
java FileName
```

Example:

``` text
javac HelloWorld.java
java HelloWorld
```
